# 2-Minute Demo Script

Record your screen with **QuickTime** (File → New Screen Recording) or [Loom](https://loom.com). Speak while you click. Aim for 1:45–2:00.

| Time | Show on screen | Say |
|---|---|---|
| 0:00–0:15 | The live URL in an incognito window | "Hi, I'm Marc. This is ShortlistAI, an AI resume screener for HR generalists at small companies. They get hundreds of applications per role and have to shortlist fast and fairly." |
| 0:15–0:30 | Click **Load sample data**. Scroll over the job description and the 4 resumes. | "Here's a real-style BPO team lead posting and four applicants. Notice that Applicant A's resume lists her age, civil status and religion, like many Philippine resumes do." |
| 0:30–0:45 | Click **Screen 4 candidates**. While it loads, point at the loading text. | "When I click screen, the app first removes names, contact details, age, sex, civil status and religion, so the AI never sees them. Then Claude checks every resume against every requirement." |
| 0:45–1:15 | The results: the comparison matrix, then the #1 card with evidence quotes | "Here's the ranked shortlist. Every requirement is marked met, partial or not met, and each one quotes the exact words from the resume, so I can verify it in seconds. The score isn't made up by the AI. It's a transparent formula, and must-haves count double." |
| 1:15–1:30 | Scroll to strengths, gaps and interview questions. Click **Copy**. | "For each candidate I get strengths, gaps, and three interview questions aimed at those gaps, ready to copy." |
| 1:30–1:40 | Click **Download CSV** and open it | "I can export the whole shortlist to Excel for the hiring manager." |
| 1:40–2:00 | GitHub repo: the Actions tab with green checks, and the README | "The code is on GitHub with a CI pipeline that runs lint, type-checks, 22 unit tests, a build and a secret scan on every push. It's deployed on Vercel. Thanks for watching!" |

**Tips:** close other tabs; zoom the browser to 110%; run the screening once *before* recording so you know how long it takes. Upload the video to YouTube (Unlisted) or Google Drive (Anyone with the link can view), then **test the link in incognito**.
